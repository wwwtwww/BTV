## 🛠️ 二、准备工作与安装途径

### 途径 A：应用内 OTA 在线升级（推荐已有旧版设备使用）
1. 电视端打开已有版本（如 `v0.4.6` 或 `v0.4.7`）；
2. 导航至左侧侧边栏底部 **「设置」** → **「关于」**；
3. 点击 **「检查更新」**；
4. 观察是否能成功检测到 `v0.4.8` 新版本弹窗，点击「立即下载并更新」，下载完成后系统将弹出安装器覆盖安装。

### 途径 B：电脑 ADB 无线安装（推荐开发者使用）
1. 确保电视与电脑在同一 Wi-Fi 局域网下，在电视设置中开启「开发者选项」与「ADB 调试」；
2. 电脑终端执行连接与安装：
   ```bash
   # 连接电视 (IP 查看电视网络设置)
   adb connect 192.168.x.x:5555

   # 安装下载的发布包 (保留数据覆盖安装)
   adb install -r BTV_188_0.4.8.r188.17ecd33_release.apk
   ```

### 途径 C：U 盘传统安装
1. 从电脑下载 `BTV_188_0.4.8.r188.17ecd33_release.apk` 拷贝至 U 盘；
2. 插入电视 USB 口，通过电视内置的「文件管理器」打开并允许未知应用安装。

## 📋 三、真机体验与验收测试清单 (Checklist)

### 1. 桌面展示与冷启动表现
- [ ] **16:9 Leanback 电视横幅**：在 Android TV 主屏应用推荐行中，确认横幅比例正常（640×360 比例），无拉伸失真；
- [ ] **应用图标**：在电视「全部应用」网格中，确认经典粉蓝渐变小电视图标边缘清晰，**底色与边角无暗黑或裁切异常**；
- [ ] **冷启动秒开率**：点击图标启动应用，冷启动至首页加载完成应保持在 2 秒左右，无白屏/黑屏闪烁。

### 2. 视频点播与多分 P 播放（重点功能）
- [ ] **即点即播体验**：首页任意视频卡片按遥控器 `确认键`，验证是否默认直接进入全屏播放，过渡自然；
- [ ] **多分 P 选集起播验证**：
  1. 找一个多集视频（如多 P 纪录片、番剧或合集教程）；
  2. 在视频详情或播放器选集面板中**选择非第一集（例如 P3 或 P5）**进入；
  3. **确认起播内容确为所点击的目标分 P**，而非被覆盖为默认 P1。
- [ ] **播放完毕自动切集与画质继承**：
  1. 将播放进度拖动到当前视频末尾（倒数 5~10 秒）；
  2. 观察倒计时结束后是否平滑切换至下一集；
  3. 切换后确认上一集设置的清晰度（如 1080P/4K）、编码格式（HEVC/AVC）以及音质被**平滑继承**。

### 3. 播放控制与大屏遥控器交互
- [ ] **方向键寻焦与控制**：
  - `方向左/右`：步进快退与快进（显示时间码微调浮层）；
  - `方向上/下`：呼出轻量控制条与下推式泳道（视频不中断）；
  - `确认/播放键`：播放 / 暂停即时响应。
- [ ] **菜单键 (Menu)**：
  - 首页卡片聚焦时按 `Menu` 键：弹出快捷面板（稍后再看、关注 UP 主、查看空间、详情页）；
  - 播放器中按 `Menu` 键：呼出播放参数面板（清晰度、倍速、弹幕开关、音轨）。
- [ ] **退出与返回**：按 `返回键` 时先关闭浮层/抽屉，全屏播放时按返回键平滑退出至上级界面。

### 4. 画质、音质与弹幕引擎负载
- [ ] **最高画质适配**：具备大会员凭证时，测试 4K、1080P60、杜比全景声切换，画面无卡死或音画不同步；
- [ ] **弹幕分段加载与流式渲染**：
  - 在弹幕密度较高的人气视频中，开启弹幕观看 3~5 分钟，画面维持平稳无掉帧；
  - 跨度 30 分钟以上的大跨度进度条拖拽，观察弹幕是否在 1~2 秒内分段加载补齐，无切集残留弹幕。

### 5. 遥控器与侧边抽屉动效
- [ ] **折叠/展开过渡**：在首页按 `方向左` 移动到最左侧导航栏，抽屉应平滑从 72dp 图标栏展开至 220dp 完整菜单；
- [ ] **焦点精准回弹**：从导航栏按 `方向右` 移出时，焦点应精准恢复至内容区原本停驻的卡片，无丢焦现象。

## 🔍 四、异常捕获与调试手段（内置日志服务）

如果在电视体验过程中遇到任何卡顿、播放失败或崩溃闪退，可利用 BTV 内置的 **局域网诊断日志服务** 快速排查：

### 步骤 1：开启电视端日志服务
1. 进入应用左侧菜单 **「设置」** → **「诊断日志」**；
2. 开启 **「启用本地日志服务器」** 开关；
3. 界面会显示当前设备的内网访问地址，例如：`http://192.168.1.100:8080`。

### 步骤 2：电脑浏览器实时查看
1. 打开同一 Wi-Fi 下的电脑或手机浏览器，输入上述地址；
2. 页面提供实时 Logcat 流、HTTP 接口请求日志、内存与播放器状态看板；
3. 遇到问题时可直接在网页端点击 **「导出日志 (Export)」**。
