## 一、快速入门

### 启动与登录

1. 打开 BTV 应用，进入首页。
2. 按 **左方向键** 将焦点移至左侧导航栏，导航栏会自动展开。
3. 按 **上方向键** 将焦点移至导航栏顶部的 **用户头像/登录入口**。
4. 按 **确认键** 打开用户面板，选择「账号管理」进行 B 站账号登录。

> **提示**：登录需要扫码或输入账号密码，建议使用手机 B 站 App 扫码登录更为便捷。

### 认识侧边导航栏

侧边导航栏是 BTV 的核心导航组件，位于屏幕左侧。

```
┌────────────┬──────────────────────────────────────┐
│            │                                      │
│  🏠 主页   │           内容区域                    │
│  🔍 搜索   │                                      │
│  👤 个人   │                                      │
│  📺 分区   │                                      │
│  🎬 影视   │                                      │
│  📡 直播   │                                      │
│            │                                      │
│  ⚙ 设置   │                                      │
│            │                                      │
└────────────┴──────────────────────────────────────┘
     ↑ 侧边导航栏
```

**导航栏行为**：

| 状态 | 宽度 | 显示内容 |
|------|------|----------|
| 折叠态 | 72dp | 仅图标 |
| 展开态 | 220dp | 图标 + 文字 |

- 焦点进入左侧栏时 → **自动展开**
- 按 **右方向键** 焦点移出到内容区 → **自动折叠**
- 当前选中项左侧有 **4dp 竖条** 指示

**导航项一览**（自上而下）：

| 图标 | 名称 | 功能 |
|------|------|------|
| 👤 | 用户头像/登录入口 | 打开用户面板 |
| 🏠 | 主页 | 返回首页 |
| 🔍 | 搜索 | 搜索视频/用户 |
| 👤 | 个人 | 稍后再看/历史/收藏/追番 |
| 📺 | 分区 | UGC/PGC 分区浏览 |
| 🎬 | 影视 | 番剧/电影/纪录片等 |
| 📡 | 直播 | 直播浏览 |
| ⚙ | 设置 | 应用设置（底部） |

### 遥控器按键说明

BTV 针对遥控器做了完善的按键映射，以下是各按键的功能：

| 按键 | 通用功能 |
|------|----------|
| **方向键（↑↓←→）** | 界面导航、焦点移动 |
| **确认键**（OK/Center） | 确认选择、短按播放/暂停 |
| **返回键**（Back） | 返回上一页、关闭弹窗 |
| **菜单键**（Menu） | 上下文操作（刷新、筛选、设置等，详见各页面说明） |

> **关于菜单键**：部分遥控器没有独立菜单键，BTV 兼容键码 `763`。如果您的遥控器有「更多」键或长按确认键可触发菜单，也能正常使用。

## 二、首页浏览

### Tab 切换

首页顶部有导航 Tab 栏：

```
┌──────────────────────────────────────────────────┐
│  [精选]  [推荐]  [热门]  [动态]                    │ ← TopNav Tab 栏
├──────────────────────────────────────────────────┤
│                                                  │
│              内容区域                              │
│                                                  │
└──────────────────────────────────────────────────┘
```

**操作方式**：
1. 在首页内容区按 **上方向键**，焦点移至顶部 Tab 栏。
2. 按 **左/右方向键** 切换 Tab（精选 → 推荐 → 热门 → 动态）。
3. 按 **确认键** 选中当前 Tab，加载对应内容。

**刷新当前 Tab**：焦点在 Tab 栏时，按 **菜单键** 可刷新当前 Tab 的数据。

### 看板与泳道

首页内容区由以下部分组成：

- **Hero Showcase 沉浸式看板**：位于顶部，展示精选内容的大图看板。看板不会抢夺焦点，当下方视频卡片获焦 400ms 后会自动驱动看板切换。
- **泳道（横向卡片列表）**：
  - 「为你推荐」泳道
  - 「关注动态」泳道（需登录）
  - 「今日热门」泳道

每条泳道标题栏采用极简纯文本设计，横向滚动列表末尾常驻大屏 **「查看全部」卡片**（与视频卡片等宽等高，带向右圆环箭头）。

**浏览操作**：
- 按 **下方向键** 在不同泳道之间上下切换（焦点在泳道间垂直对齐平滑穿梭）。
- 按 **左/右方向键** 在当前泳道的卡片之间横向滚动浏览。
- **直达完整列表**：按 **右方向键** 一路向右滚动至列表末端，即可直接选中「查看全部」卡片，按 **确认键** 直达对应的单分类沉浸瀑布流（推荐 / 动态 / 热门）。
- 列表距末尾 4 项时自动触发后台预加载，畅快滑行无需等待。

### 视频卡片操作

视频卡片是 BTV 中最核心的交互元素。

**卡片布局**：

```
┌─────────────────────────────────────┐
│  ┌─────────────────────────────┐    │
│  │      封面图片 (16:10)         │    │
│  │  ┌───────────────────────┐  │    │
│  │  │ ▶ 12.3万  💬 9999  10:42│  │    │ ← 播放量/弹幕/时长
│  │  └───────────────────────┘  │    │
│  │  ▓▓▓▓▓▓▓▓▓░░░░ 进度条       │    │ ← 观看进度（如有）
│  │        [菜单 更多] ← 聚焦时显示│    │ ← 操作提示角标
│  └─────────────────────────────┘    │
│  视频标题（2行省略）                  │
│  👤 UP主名称 · 发布时间              │
└─────────────────────────────────────┘
```

#### ⭐ "菜单 更多" 详解

> **重要说明**：卡片右上角的「菜单 更多」**不是一个独立的可聚焦按钮**，而是一个视觉提示角标。它仅在卡片获得焦点时显示（黑底半透明胶囊样式，70% 透明度），提醒您可以通过以下方式打开快捷操作：

**触发快捷操作弹窗的方式（二选一）**：

| 操作 | 方法 |
|------|------|
| **方式一：菜单键** | 聚焦卡片后，按遥控器 **菜单键（Menu）** |
| **方式二：长按** | 聚焦卡片后，**长按确认键** |

两种方式都会唤起 **VideoCardActionDialog 快捷操作弹窗**。

#### 快捷操作弹窗

弹窗为底部半屏 ActionSheet 样式（YouTube TV 风格）：

```
┌──────────────────────────────────────────┐
│  ┌──────────┐                            │
│  │  封面图   │  视频标题                   │
│  │  (160dp)  │  👤 UP主名 · ⏱ 10:42      │
│  └──────────┘                            │
├──────────────────────────────────────────┤
│                                          │
│  [添加到稍后再看] [查看详情] [UP主空间] ... │ ← 横向胶囊按钮
│                                          │
└──────────────────────────────────────────┘
```

**可用操作项**（根据上下文动态显示）：

| 操作 | 说明 | 出现条件 |
|------|------|----------|
| 移出稍后再看 | 从稍后再看列表移除 | 当前在稍后再看列表 |
| 从历史删除 | 删除观看记录 | 当前在历史记录 |
| 取消收藏 | 取消视频收藏 | 当前在收藏夹 |
| 取消追番 | 取消追番 | 当前在追番列表 |
| 添加到稍后再看 | 加入稍后再看 | 非稍后再看列表时 |
| 查看详情 | 进入视频详情页 | 始终可用 |
| UP主空间 | 查看 UP 主主页 | 始终可用 |

**操作方式**：
1. 弹窗打开后，焦点自动定位到首个管理操作项。
2. 按 **左/右方向键** 在操作按钮之间滚动。
3. 按 **确认键** 执行选中的操作。
4. 按 **返回键** 关闭弹窗。

#### 卡片基本操作

| 操作 | 方法 |
|------|------|
| 进入视频播放 | 聚焦卡片后按 **确认键**（短按） |
| 打开快捷操作 | 聚焦卡片后按 **菜单键** 或 **长按确认键** |

## 三、视频播放

### 进入播放

- 在视频卡片上按 **确认键** → 直接进入视频播放（即点即播）。
- 从快捷操作弹窗中选择「查看详情」→ 进入视频详情页 → 再按确认键播放。

### 播放器控制

播放器采用沉浸式设计，默认隐藏控制层，画面全屏展示。

**信息栏布局**（按 **下方向键** 唤出）：

```
┌────────────────────────────────────────────────────────┐
│  视频标题             [8K/4K/杜比/Hi-Res等音画质徽标]   │ ← 顶部信息
├────────────────────────────────────────────────────────┤
│  ▓▓▓▓▓▓▓░░░░░░░░░░░░░░░░░░░░░░░░  03:21 / 10:42        │ ← 进度条（可获焦）
├────────────────────────────────────────────────────────┤
│  [▶⏸] [弹幕] [清晰度] [画面比例] [选集] [相关推荐]       │ ← 底部操作按钮行
│  [视频详情] [UP主空间] [循环播放] [点赞互动] [评论区]    │
└────────────────────────────────────────────────────────┘
```

**按钮行功能一览（自左向右）**：

| 图标按钮 | 说明 | 显示条件 |
|----------|------|----------|
| **播放 / 暂停** | 切换播放与暂停状态 | 始终常驻 |
| **弹幕开关** | 快速开启或关闭全屏弹幕渲染 | 始终常驻 |
| **清晰度与设置** | 唤起播放器侧边三级设置菜单 | 始终常驻 |
| **画面比例** | 循环切换默认/16:9/4:3/填充比例 | 始终常驻 |
| **选集** | 打开分集与多 P 列表横向选集轨 | 多 P 视频或剧集可用 |
| **相关推荐** | 打开相关推荐视频横向抽屉 | 有推荐数据时显示 |
| **视频详情** | 查看完整视频简介与分区标签 | UGC 视频可用 |
| **UP 主空间** | 直达 UP 主主页浏览投稿 | UGC 视频可用 |
| **循环播放** | 开启 / 关闭单片循环播放 | 始终常驻 |
| **点赞互动** | 打开点赞、投币、收藏快捷弹窗 | 始终常驻 |
| **评论区** | 打开右侧大屏沉浸式评论列表弹窗 | 始终常驻 |

**按键控制一览**：

| 按键 | 覆盖层关闭时（全屏画面） | 覆盖层打开时（信息栏/弹窗） |
|------|--------------------------|----------------------------|
| **左方向键** | 快退（连续按步长加速，10s→15s→...） | 关闭覆盖层或在控件间左移 |
| **右方向键** | 快进（连续按步长加速） | 关闭覆盖层或在控件间右移 |
| **上方向键** | 打开选集轨（多 P）；无分集时提示“暂无分集” | 从按钮行上移至进度条；关闭相关推荐 |
| **下方向键** | 呼出底部信息栏与可获焦进度条 | 从进度条下移至按钮行；打开选集/推荐 |
| **确认键短按** | 播放 / 暂停（连播浮层展示时立即播放下一集） | 触发选中的按钮功能或退出覆盖层 |
| **确认键长按** | 快速打开播放器设置菜单 | — |
| **菜单键** | 打开 / 关闭播放器设置菜单 | 关闭当前打开的覆盖层/菜单 |
| **返回键** | 无覆盖层时**双击返回键**退出播放器 | 先关闭当前覆盖层；取消连播倒计时 |

**快进/快退加速**：连续按左/右方向键时，步长会逐渐增大（基础 10 秒，每连续 5 次增加 5 秒），200ms 内连续按键触发加速。

**信息栏自动收起**：信息栏显示后 5 秒无操作会自动隐藏。

**焦点导航**：
- 进度条 → 按 **下** → 按钮行
- 按钮行 → 按 **上** → 进度条
- 按钮行 → 按 **下** → 选集轨 / 相关推荐

### 设置菜单

按 **菜单键** 或 **长按确认键** 打开播放器设置菜单：

```
┌────────────────────────────┐
│  倍速    │                  │
│  画质    │   设置面板       │
│  声音    │                  │
│  弹幕    │                  │
│  字幕    │                  │
└────────────────────────────┘
```

采用三态焦点模型：左侧导航 ↔ 中间面板 ↔ 右侧具体设置项。

### 选集与连播

- **打开选集轨**：播放中按 **上方向键**（如有多 P 或分集）。
- **选集操作**：焦点在选集轨上时，按 **左/右方向键** 选择分集，按 **确认键** 跳转。
- **连播**：播放完当前视频后自动播放下一个（如有）。连播中按 **返回键** 可取消连播。

### 退出播放器

| 场景 | 操作 |
|------|------|
| 覆盖层打开 | 按 **返回键** 关闭覆盖层 |
| 连播中 | 再按 **返回键** 取消连播 |
| 无覆盖层 | **双击返回键** 退出播放器 |

> **提示**：退出播放器需要"双击"返回键是防误触设计，快速连按两次即可。

## 四、个人空间

个人页面包含 4 个子 Tab，顶部有导航栏和「全部播放」按钮。

### 页面布局

```
┌────────────────────────────────────────────────────┐
│  [稍后再看] [历史记录] [收藏夹] [追番追剧]    [全部播放]│ ← TopNav
├────────────────────────────────────────────────────┤
│                                                    │
│              内容区域                                │
│         （根据选中 Tab 切换）                        │
│                                                    │
└────────────────────────────────────────────────────┘
```

### Tab 切换

1. 在个人页面内容区按 **上方向键**，焦点移至顶部 Tab 栏。
2. 按 **左/右方向键** 在 Tab 之间切换：稍后再看 → 历史记录 → 收藏夹 → 追番追剧。
3. 按 **确认键** 选中 Tab，内容区会横向滑动切换。

> Tab 排序可在「设置 → 界面设置 → 个人页 Tab」中自定义。

### ⭐ 全部播放使用方法

> **「全部播放」按钮位于 TopNav 导航栏的最右侧**，仅在「稍后再看」和「收藏夹」Tab 下有数据时才会显示。

**详细导航步骤**：

```
步骤 1：进入「个人」页面
        ↓
步骤 2：确保当前在「稍后再看」或「收藏夹」Tab
        ↓
步骤 3：按 ↑ 上方向键，将焦点移至顶部 Tab 栏
        ↓
步骤 4：按 → 右方向键，一直移动到最右侧的「全部播放」按钮
        ↓
步骤 5：按 OK 确认键，开始连播全部视频
```

**各 Tab 下的「全部播放」行为**：

| 当前 Tab | 全部播放行为 |
|----------|-------------|
| 稍后再看 | 连播全部稍后再看视频 |
| 收藏夹 | 连播当前收藏夹内全部视频 |
| 历史记录 | 按钮不显示 |
| 追番追剧 | 按钮不显示 |

> **找不到「全部播放」？** 请确认：① 当前是否在「稍后再看」或「收藏夹」Tab；② 列表是否有数据；③ 焦点是否已移至顶部 Tab 栏（按上方向键直到顶部），然后持续按右方向键到达最右侧。

### 稍后再看

- **布局**：4 列网格，分为「未看完」和「已看完」两组。
- **显示信息**：封面、标题、播放进度条。
- **操作**：
  - 按 **确认键** → 播放视频
  - 按 **菜单键** → 打开快捷操作弹窗（可「移出稍后再看」等）

### 历史记录

## 十、常见问题 (FAQ)

### ❓ 首页精选页怎么进入各个分类（推荐/动态/热门）的完整瀑布流列表？

有两种最便捷的前往方式：
1. **泳道末尾直达（推荐）**：在首页任意泳道（为你推荐、关注动态、今日热门）中，按 **→ 右方向键** 一路向右滚动到最末尾，选中常驻的 **「查看全部」** 卡片，按 **确认键** 即可进入对应的单分类海量瀑布流。
2. **顶部 Tab 切换**：在内容区按 **↑ 上方向键** 进入顶部导航 Tab 栏，按 **← / → 左/右方向键** 切换到「推荐」、「热门」或「动态」标签。

### ❓ 遥控器没有独立菜单键（Menu）怎么办？

如果您的遥控器没有专门的“菜单”按键，可通过以下多种替代途径无缝使用所有功能：
- **卡片快捷菜单**：移动光标至视频卡片后，**长按确认键（OK）** 即可唤起快捷操作弹窗。
- **播放器设置菜单**：在全屏播放状态下，**长按确认键（OK）** 即可快速打开侧边设置面板。
- **系统兼容键码**：BTV 原生兼容电视端常见功能键码（如 KeyCode `763`）。
- **完全自定义按键**：进入「**设置 → 播放设置 → 自定义快捷键**」，将遥控器上现有的任意空闲实体键（如色彩键、数字键等）直接映射为菜单功能。

### ❓ 在"个人"页面找不到"全部播放"按钮？

这是用户最常问的问题。**「全部播放」不是一个始终可见的按钮**，它有以下限制：

**显示条件**：
- 仅在「**稍后再看**」或「**收藏夹**」Tab 下才会显示
- 且当前列表**有数据**时才会出现

**导航步骤**：

> 1. 进入「**个人**」页面
> 2. 切换到「**稍后再看**」或「**收藏夹**」Tab
> 3. 按 **↑ 上方向键**，将焦点一直移到**顶部 Tab 栏**
> 4. 按 **→ 右方向键**，沿着 Tab 栏一直向右移动，经过所有 Tab 后到达最右侧的「**全部播放**」按钮
> 5. 按 **确认键** 即可开始连播

```
[稍后再看] → [历史记录] → [收藏夹] → [追番追剧] → ... → [⭐ 全部播放]
                                                         ↑
                                                    在这里！
```

### ❓ 视频卡片右上角的"菜单 更多"怎么点不到？

**「菜单 更多」不是一个独立的可聚焦按钮！** 它是一个视觉提示角标，仅在卡片获得焦点时显示，提醒您该卡片支持快捷操作。

**正确的触发方式**：

| 方式 | 操作 |
|------|------|
| **菜单键** | 将焦点移到视频卡片上 → 按遥控器的 **菜单键（Menu）** |
| **长按** | 将焦点移到视频卡片上 → **长按确认键（OK）** |

> 两种操作都会弹出「快捷操作弹窗」，可进行添加到稍后再看、查看详情、访问 UP 主空间等操作。

### ❓ 怎么退出播放器？

退出播放器需要 **双击返回键**：

1. 如果覆盖层（信息栏/选集轨等）打开 → 先按 **返回键** 关闭覆盖层
2. 如果正在连播 → 再按 **返回键** 取消连播
3. 最后再按 **返回键**（第二次）→ 退出播放器

> 双击设计是为了防止误触退出。快速连按两次返回键即可。

### ❓ 侧边导航栏怎么收起来？

不需要手动收起！导航栏会自动管理：
- 焦点移到左侧栏 → **自动展开**
- 按 **右方向键** 焦点移到内容区 → **自动折叠**

### ❓ 搜索页返回键行为异常？

搜索页的返回键采用分层逻辑：
1. 焦点在右栏（结果区）→ 按返回键 → **退回左栏**（搜索输入区）
2. 焦点在左栏，有输入内容 → 按返回键 → **清空输入**
3. 焦点在左栏，无输入 → 按返回键 → **退出搜索页**

> 这是设计行为，不是 Bug。需要从结果区返回两次才能退出搜索页。

### ❓ 菜单键在不同页面行为不同？

菜单键是**上下文相关**的，在不同位置有不同功能：

| 焦点位置 | 菜单键行为 |
|----------|------------|
| 首页 Tab 栏 | 刷新当前 Tab |
| 视频卡片 | 打开快捷操作弹窗 |
| 播放器中 | 打开/关闭设置菜单 |
| 搜索结果页 TopNav | 打开视频筛选 |
| UGC 分区页 | 刷新当前分区 |
| 直播页 | 刷新所有数据 |
| 个人页 | 刷新当前 Tab |
| 追番页 | 打开筛选弹窗 |

### ❓ 快进/快退速度太慢？

BTV 支持快进加速：连续按左/右方向键时，步长会逐渐增大。基础步长 10 秒，每连续按 5 次增加 5 秒（10s → 15s → 20s → ...），200ms 内连续按键触发加速。

### ❓ 界面太小/太大？

进入「**设置 → 界面设置 → 界面缩放**」，可调整全局缩放比例（0.5 ~ 5.0 倍）。
