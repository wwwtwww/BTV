# BTV v0.6.0 真机验收操作手册

> 配套文档：[真机测试与验收指南](真机测试与验收指南.md) | [PRD §4.13 屏保](PRD.md) | CHANGELOG [v0.6.0]
>
> **目标**：验收 v0.6.0（commit `fec1a00`，versionCode 266）四大变更——全局防烧屏屏保、切集竞态三重防护、用户锁安全旁路修复、数据库迁移兜底移除。
>
> **预计耗时**：45~60 分钟（含屏保等待时间）。

---

## 一、前置准备

### 1. 连接电视

```powershell
# 电视与电脑同一局域网；电视设置中开启「开发者选项」与「ADB 调试」
adb connect 192.168.x.x:5555
adb devices          # 应列出设备且状态为 device
```

### 2. 确认当前版本

```powershell
adb shell dumpsys package dev.frost819.btv | findstr versionName
adb shell dumpsys package dev.frost819.btv | findstr versionCode
```

- **v0.5.12（versionCode 264）→ 走验收 1 的 OTA 流程**（推荐，顺便验证升级链路）；
- **更低版本或无法启动 → 侧载**：

```powershell
# 从 https://github.com/wwwtwww/BTV/releases/tag/v0.6.0 下载 APK 后：
adb install -r BTV_266_0.6.0.r266.fec1a00_release.apk
```

> 注意：v0.6.0 移除了 `fallbackToDestructiveMigration`，**从 v0.5.11 及以下直接升级若崩溃说明迁移有问题**，请立即记录（这是本次验收的重点之一，见验收 2）。

## 二、验收清单

### 验收 1：OTA 升级链路（v0.5.12 → v0.6.0）

| # | 步骤 | 预期结果 |
|---|---|---|
| 1.1 | v0.5.12 打开 BTV → 设置 → 关于 → 检查更新 | 弹出 v0.6.0 更新卡（版本对比/体积/更新说明） |
| 1.2 | 更新说明长文本按方向键滚动阅读 | 显示屏保/切集修复等 v0.6.0 章节 |
| 1.3 | 确认下载 → 等待完成 → 系统安装器拉起 | 安装过程无 ANR、无「无路可逃」假死 |
| 1.4 | 安装完成重新打开 BTV | 应用正常启动，登录状态/搜索历史/用户锁**全部保留** |

**1.4 即验收 2（Room 迁移）**：老数据（DB v5）在 v0.6.0 首启时经 `MIGRATION_4_5`（幂等 IF NOT EXISTS）升级。启动即崩 = 验收失败，需用验收 6 抓日志。

### 验收 2：数据库迁移兜底移除的行为确认

v0.6.0 起，缺失迁移路径会**直接崩溃而不是静默清库**（防止账户/搜索历史被清空）。对正常升级路径无感；验收要点就是「1.4 登录态保留 + 启动不崩」。

### 验收 3：全局防烧屏屏保（11 用例）

> 验收前确认：设置 → 音视频 → **防烧屏屏保超时** 为 3 分钟（默认）。

| # | 用例 | 步骤 | 预期结果 |
|---|---|---|---|
| 3.1 | 主页空闲触发 | 打开 app 进主页，不操作等 3 分钟 | 屏保（微光时钟）出现 |
| 3.2 | 暂停触发 | 播放视频 → 暂停 → 等 3 分钟 | 屏保出现 |
| 3.3 | 播完回主页触发 | 单 P 视频播完自动回主页 → 等 3 分钟 | 屏保出现 |
| 3.4 | 播放中不触发 | 播放视频持续 10 分钟 | 屏保不出现（缓冲/加载时也不误弹） |
| 3.5 | 按键唤醒 | 屏保出现后按任意遥控器按键 | 屏保消失，画面恢复 |
| 3.6 | 唤醒后重新计时 | 唤醒后立即再等 3 分钟 | 屏保再次出现 |
| 3.7 | 触屏唤醒 | 屏保出现后点击屏幕 | 屏保消失 |
| 3.8 | 漂移防烧屏 | 屏保出现后持续观察 1~2 分钟 | 时钟每约 30 秒平滑漂移，无固定静止像素 |
| 3.9 | 配置即时生效 | 设置超时改为 1 分钟 → 回主页等待 | 1 分钟后触发（无需重启） |
| 3.10 | 禁用验证 | 设置超时改为「关闭」→ 等 10 分钟 | 屏保不出现 |
| 3.11 | 后台恢复重置 | 等 2 分钟 → Home 退后台 → 等 5 分钟 → 回 app | 不立即触发，重新计满 3 分钟才出现 |

**补充（播放器错误态）**：断网后打开一个视频 → 出现错误提示卡后静置超时 → **屏保不应遮挡错误提示与重试入口**（黑名单策略：错误态保持常亮、屏保被抑制）。

### 验收 4：切集竞态三重防护（本次 P0 修复）

> 准备：找一个**多分 P / 合集**视频（≥10 集）。

| # | 步骤 | 预期结果 |
|---|---|---|
| 4.1 | 从推荐卡直接起播多 P 视频（cid==0 延迟路径），详情加载中**快速连按下一集 2~3 次** | 最终起播的是**最后一次按的那一集**，标题/进度条/弹幕与该集对应，无双弹幕叠画 |
| 4.2 | 播放中通过底部选集轨**快速连续切换分 P** | 每次切集弹幕立即清空后加载新集弹幕，无旧集残留 |
| 4.3 | 切集后返回主页再进入 | 历史进度记录的是**实际观看的那一集**，无串集 |
| 4.4 | 切集瞬间观察心跳上报 | 断网切集/切集后无「上一集进度写进新集」现象（历史页验证） |

### 验收 5：用户锁安全旁路修复（本次 P0 修复）

| # | 步骤 | 预期结果 |
|---|---|---|
| 5.1 | 登录后进 设置 → 用户锁 → 设新密码（画方向图案） | 保存成功提示「用户锁已保存」 |
| 5.2 | **清除锁后立刻重新进入用户锁设置页，页面刚出现的瞬间（数据未加载完）连按 OK 键多次** | 显示「加载中」文案、不进入输入态；**锁不会被误清除**；加载完成后进入正常输入流程 |
| 5.3 | 断网（或路由器拦截）后进用户锁设置页 | 出现「加载失败，按确认键重试」；按 OK 重新发起查询；期间方向键被拦截 |
| 5.4 | 恢复网络 → 按确认重试 → 正常设锁 | 状态机恢复，设锁成功 |

### 验收 6：异常捕获与日志抓取

遇到崩溃/卡顿时：

1. 电视端：设置 → 诊断日志 → 开启「启用本地日志服务器」；
2. 电脑浏览器访问界面显示的地址（如 `http://192.168.1.100:8080`）；
3. 网页端查看实时 Logcat / HTTP 请求日志 / 内存看板，点击「导出日志」；
4. 也可抓 Room 迁移崩溃现场：

```powershell
adb logcat -d | findstr /i "Migration room IllegalStateException crash" > btv_migration.log
adb logcat -d -s AndroidRuntime:E > btv_crash.log
```
